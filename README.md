# 🐍 Snake Game Using Python

A classic Snake Game developed using **Python and Pygame**. Control the snake, collect food, increase your score, and try to beat your highest score!

## 🎮 Features

- **Interactive Gameplay:** Control the snake using arrow keys or WASD.
- **Score System:** Earn 10 points every time the snake eats food.
- **High Score Tracking:** Save your highest score in a text file.
- **Sound Effects & Background Music:** Enjoy audio during gameplay.
- **Increasing Difficulty:** The snake's speed increases as you collect food.
- **Cheat Mode:** Use special keyboard keys to modify the game.
- **Game Controls:** Restart the game or exit using the keyboard.

## 🛠️ Technologies Used

- Python
- Pygame
- Random module
- OS module

## 🚀 How to Run

1. Install Python on your computer.
2. Install Pygame:

   ```bash
   pip install pygame
   ```

3. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

4. Open the project folder.
5. Make sure all required images and audio files are present.
6. Run the game:

   ```bash
   python snake_game.py
   ```

## 🕹️ Controls

| Key | Action |
|---|---|
| Arrow Keys / WASD | Move the snake |
| Enter / Space | Start or restart the game |
| Esc | Exit the game |
| 7 | Increase sensitivity |
| 9 | Add 20 points |
| 5 | Increase speed |
